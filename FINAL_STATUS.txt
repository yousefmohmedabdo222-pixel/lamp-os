🎯 INSTALLATION WORKFLOW

1. PREPARE USB
   → Download Rufus (https://rufus.ie)
   → Select lamp-os-complete-installer.iso
   → Select USB drive (8GB+)
   → Click START

2. BOOT FROM USB
   → Insert USB
   → Restart computer
   → Press boot menu key (F12/F2/ESC)
   → Select USB device

3. INSTALLATION MENU
   → Select [1] Install LAMP OS to Disk
   → System shows live environment

4. DISK SELECTION
   → Choose target disk
   → Confirm format warning (type YES)

5. PARTITIONING
   → Select [1] Use Entire Disk
   → Auto creates GPT + EFI + root

6. INSTALLATION
   → Creates partition table
   → Formats partitions
   → Extracts system files
   → Installs bootloader
   → Complete!

7. REBOOT
   → Select [1] Reboot System
   → System boots into new installation

8. FIRST BOOT SETUP
   → Display resolution selector
   → Create user account
   → Set password (optional)
   → Select profile picture
   → Desktop launches

9. READY TO USE
   → Desktop menu appears
   → System fully configured
   → All tools available

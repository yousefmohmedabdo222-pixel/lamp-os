1. GETTING STARTED
━━━━━━━━━━━━━━━━━

Welcome to LAMP OS! This is a minimal Linux distribution designed to be:
- Lightweight
- Fast
- Easy to use
- Fully functional

After boot, you'll see a shell prompt: 🪔 lamp-os:~ \$

You can type commands or use the interactive menu system.

2. AVAILABLE COMMANDS
━━━━━━━━━━━━━━━━━━━

File Operations:
  ls, ll, la, l        - List files
  cp, mv, rm           - Copy, move, remove
  cat, more, less      - View files
  touch, mkdir         - Create files/directories
  tar, gzip            - Archive operations

Text Processing:
  grep, sed, awk       - Text search and processing
  echo, printf         - Output text
  sort, uniq, wc       - Sort and count
  cut, tr              - Text transformation

System Info:
  uname, uptime        - System information
  ps, top              - Process information
  df, du               - Disk usage
  free                 - Memory information

Network:
  ip, ifconfig         - Network configuration
  ping, telnet         - Network testing
  ssh, scp             - Secure shell
  wget, curl           - Download files

3. LAMP OS TOOLS
━━━━━━━━━━━━━━━━

LAMP OS provides several specialized tools:

lamp-menu
---------
Interactive menu system with options for:
- Launch GUI
- Access shell
- View system info
- Monitor resources
- Create test files

Usage: lamp-menu

lamp-network
-----------
Network configuration tool:
- Show network interfaces
- Configure DHCP or static IP
- Test connectivity
- Manage DNS settings

Usage: lamp-network

lamp-system
-----------
System utilities:
- Monitor disk usage
- Check processes
- View CPU/memory info
- System backup
- Cleanup temporary files
- Full system diagnosis

Usage: lamp-system

lamp-gui
---------
Graphical user interface:
- Simple text-based GUI
- System information display
- Easy navigation

Usage: lamp-gui
Or: /opt/lamp-gui/lamp-gui

4. NETWORKING
━━━━━━━━━━━━

View Network Status:
  ip addr show          - Show IP addresses
  ip link show          - Show interfaces
  ip route show         - Show routes
  netstat               - Show connections

Configure Network:
  ip link set eth0 up                    - Enable interface
  ip addr add 192.168.1.100/24 dev eth0 - Add IP
  ip route add default via 192.168.1.1  - Add default route

DNS Configuration:
  cat /etc/resolv.conf              - View DNS
  echo "nameserver 8.8.8.8" > /etc/resolv.conf - Set DNS

Ping:
  ping 8.8.8.8          - Test connectivity

5. SYSTEM ADMINISTRATION
━━━━━━━━━━━━━━━━━━━━━

Mount/Unmount:
  mount                      - Show mounted filesystems
  mount -t proc proc /proc   - Mount proc
  umount /mnt/point          - Unmount

Filesystem Info:
  df -h                 - Disk free space
  du -h /path           - Directory usage
  fsck /dev/sda1        - Check filesystem

User/Permissions:
  whoami                - Show current user
  chmod 755 file        - Change permissions
  chown user:group file - Change owner

Process Management:
  ps aux                - List processes
  kill PID              - Terminate process
  killall command       - Kill by name
  jobs                  - Show background jobs
  bg, fg                - Background/foreground

6. FILE MANAGEMENT
━━━━━━━━━━━━━━━━━

Basic Operations:
  ls -lah               - List with details
  cd /path              - Change directory
  pwd                   - Print working directory
  mkdir test            - Create directory
  rm file               - Remove file
  cp src dst            - Copy file
  mv src dst            - Move/rename

Search:
  find /path -name "*.txt"      - Search by name
  find /path -type f -size +1M  - Search by size
  grep "pattern" file           - Search in file

Archive:
  tar -czf file.tar.gz /path    - Create archive
  tar -xzf file.tar.gz          - Extract archive
  gzip file                     - Compress file

7. TROUBLESHOOTING
━━━━━━━━━━━━━━━━━

System Hangs:
  - Press Ctrl+C to interrupt
  - Press Ctrl+Z to suspend
  - Use 'kill' command from another terminal

Out of Memory:
  - Check: free -h
  - Cleanup: rm -rf /tmp/*
  - Check processes: ps aux --sort=-%mem

Network Issues:
  - Check IP: ip addr show
  - Check DNS: cat /etc/resolv.conf
  - Test: ping 8.8.8.8
  - Use lamp-network tool

Filesystem Full:
  - Check: df -h
  - Find large files: du -h | sort -rh | head
  - Cleanup: rm old files

8. TIPS & TRICKS
━━━━━━━━━━━━━━

Shortcuts:
  Tab              - Auto-complete
  Ctrl+C           - Cancel command
  Ctrl+D           - Exit shell
  Ctrl+L           - Clear screen
  !previous        - Repeat previous command
  !!               - Repeat last command

Useful Combinations:
  ls -lh | grep txt        - List only .txt files
  ps aux | grep process    - Find process
  cat file | grep "text"   - Search in file
  > file                   - Redirect output
  | command                - Pipe output
  && command               - And operator
  || command               - Or operator

One-Liners:
  find . -type f -exec rm {} \;  - Remove all files recursively
  for i in $(seq 1 10); do echo $i; done  - Loop
  echo "$(date)" >> /tmp/log.txt  - Log timestamp

Environment:
  export VAR=value    - Set environment variable
  echo $VAR           - Show variable
  alias name='cmd'    - Create alias
  unalias name        - Remove alias

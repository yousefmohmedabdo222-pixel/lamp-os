🔊 SOUND EFFECTS SYSTEM (نظام الأصوات):
═══════════════════════════════════════════════════════════════════════════════

✅ 5 أصوات مختلفة:

1. Boot Sound (صوت الإقلاع)
   • تردد 1: 1000 Hz لمدة 200ms
   • تردد 2: 1200 Hz لمدة 200ms
   • تردد 3: 1500 Hz لمدة 300ms
   • تأثير: صعود تدريجي في التردد

2. Login Sound (صوت تسجيل الدخول)
   • نمط Windows 7 الكلاسيكي
   • تردد 1: 800 Hz لمدة 100ms
   • تردد 2: 1200 Hz لمدة 200ms

3. Success Sound (صوت النجاح)
   • تردد 1: 1000 Hz لمدة 100ms
   • تردد 2: 1500 Hz لمدة 200ms
   • تأثير: قفز تردد لأعلى

4. Error Sound (صوت الخطأ)
   • تردد ثابت: 400 Hz
   • تكرار 3 نقرات سريعة
   • تأثير: تنبيه واضح

5. Shutdown Sound (صوت الإيقاف)
   • تردد 1: 1500 Hz لمدة 300ms
   • تردد 2: 1200 Hz لمدة 300ms
   • تردد 3: 1000 Hz لمدة 400ms
   • تأثير: هبوط تدريجي (نقيض Boot Sound)

🚀 HOW TO USE:
═══════════════════════════════════════════════════════════════════════════════

View Individual Animation Screens:

  # شاشة الإقلاع
  bash /workspaces/lamp-os/gui/boot-screen.sh

  # شاشة البداية
  bash /workspaces/lamp-os/gui/splash-screen.sh

  # شاشة تسجيل الدخول
  bash /workspaces/lamp-os/gui/login-screen.sh

  # شاشة اختيار البارتيشن (مع اسم yousef)
  bash /workspaces/lamp-os/gui/partition-screen.sh

  # شاشة الإيقاف
  bash /workspaces/lamp-os/gui/shutdown-screen.sh

  # عرض الشعار
  bash /workspaces/lamp-os/gui/logo.sh

Play System Sounds:

  # صوت الإقلاع
  lamp-sounds boot

  # صوت تسجيل الدخول
  lamp-sounds login

  # صوت النجاح
  lamp-sounds success

  # صوت الخطأ
  lamp-sounds error

  # صوت الإيقاف
  lamp-sounds shutdown

Boot Premium Edition:

  cd /workspaces/lamp-os
  
  timeout 30 qemu-system-x86_64 -cdrom lamp-os-premium.iso -m 512M \
    -nographic -serial file:/tmp/premium.log -accel tcg

Test All Screens:

  bash /workspaces/lamp-os/test-premium.sh

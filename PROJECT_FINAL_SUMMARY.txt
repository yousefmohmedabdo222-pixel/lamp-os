🚀 HOW TO START
─────────────────────────────────────────────────────────────────────────────

STEP 1: Navigate to project
  $ cd /workspaces/lamp-os

STEP 2: Boot the system
  $ timeout 30 qemu-system-x86_64 -cdrom lamp-os-gui.iso -m 512M \
      -nographic -serial file:/tmp/boot.log -accel tcg

STEP 3: Select from menu
  • Just enter 1-9 and press Enter
  • System responds immediately
  • No typing or complex commands needed

STEP 4: Enjoy!
  • Use the tools
  • Explore the system
  • Try all options

🚀 QUICK START

Boot the system:
  timeout 30 qemu-system-x86_64 -cdrom lamp-os.iso -m 512M -nographic \
    -serial file:/tmp/boot.log -accel tcg

Check the boot:
  tail /tmp/boot.log | grep "/ #"

Access system:
  - lamp-menu: Interactive menu
  - lamp-network: Network config
  - lamp-system: System tools
  - lamp-gui: Graphics

Get help:
  lamp-help
